INFRAESTRUTURA SOB SEU CONTROLE

Meu node

Um computador pode manter um relay online. Um navegador móvel pode ajudar enquanto estiver aberto, mas o sistema pode suspendê-lo.

Relay localInicie pelo terminal Ubuntu

Ponte entre relays

Quando ativa, esta PWA encaminha eventos públicos assinados entre os relays que você selecionou. Gift wraps privados só são replicados quando foram endereçados a você, e apenas para seus relays de recebimento NIP-17; a ponte nunca lê o texto. Relays ainda veem seu endereço IP, horários e metadados do protocolo; o recurso pode consumir dados móveis. A ponte limita a 60 eventos e 2 MB de tráfego de saída por minuto, somando o envio a cada relay. Só funciona enquanto o app estiver aberto — o sistema pode suspendê-lo. Para operação contínua, use o relay do PC.
